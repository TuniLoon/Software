## 📖 Overview

TuniLoon is a high-altitude balloon platform designed to support Tunisia's agricultural, healthcare, and disaster management needs by 2056. This repository contains the **software-only prototype** for the TuniLoon system, including:

- **Mock Payload Simulator**: Simulates the balloon's sensors and telemetry
- **Ground Station Software**: Receives, decodes, logs, and visualizes telemetry data
- **Cloud Integration**: MQTT, Telegram alerts, and Sondehub integration
